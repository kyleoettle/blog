It could have been a year ago or so when I was asked "What do I think a good Api looks like".  
After thinking for a bit, I started with "It depends..."
Every now and think I think about that question and my mind starts thinking about a whole lot of different options based on what I'm currently busy with, so I guess it `still depends...`, but there is always a core them of functionality that I think makes a good Api design.  
I asked a coworker and friend of mine (Nawa) what he thinks a good Api design looks like, and we came up with what we think matter.
